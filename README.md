# 🌦️ Weather Dashboard

A responsive and interactive weather dashboard that provides real-time weather information, a 5-day forecast, temperature trends, and recent search history.

## 🚀 Features

- 🔍 Search weather by city
- 🌡️ Real-time temperature
- 💧 Humidity information
- 💨 Wind speed
- ☀️ Weather condition with icons
- 🔄 Celsius / Fahrenheit temperature toggle
- 📅 5-day weather forecast
- 📈 Temperature trend chart
- 🌈 Weather-based background themes
- 🕒 Live date, time and greeting
- 🗂️ Recent search history
- 🗄️ MongoDB database integration
- 📱 Responsive design

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Chart.js

### Backend
- Python
- FastAPI
- HTTPX

### Database
- MongoDB
- PyMongo

### Weather API
- Open-Meteo API
